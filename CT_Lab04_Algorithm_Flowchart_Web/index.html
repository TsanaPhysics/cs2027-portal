MODULE 03 • STANDARD FLOWCHART (ANSI/ISO 5807)

SYMBOL REFERENCE

สัญลักษณ์ผังงานมาตรฐาน ANSI/ISO

ดูตารางสัญลักษณ์มาตรฐาน ISO 5807:1985 ครบทั้ง 16 สัญลักษณ์ (จาก NotebookLM Deep Research)
สัญลักษณ์รูปทรงหน้าที่การใช้งานมาตรฐาน ISO 5807
Terminatorวงรี / สี่เหลี่ยมมุมมนกำหนดจุดเริ่มต้น (START) หรือจุดสิ้นสุด (END)
Preparationหกเหลี่ยมแนวนอน (Hexagon)ตั้งค่าเริ่มต้นตัวแปร สวิตช์ หรือตัวนับก่อนเข้ากระบวนการหลัก
Processสี่เหลี่ยมผืนผ้าการคำนวณ กำหนดค่าตัวแปร (←) หรือควบคุมอุปกรณ์
Decisionสี่เหลี่ยมข้าวหลามตัดจุดทดสอบเงื่อนไขตรรกศาสตร์ มีเส้นทางออกอย่างน้อย 2 ทาง
Data (I/O)สี่เหลี่ยมด้านขนานรับข้อมูลเข้า หรือแสดงผลลัพธ์ออกโดยไม่จำกัดอุปกรณ์
Predefined Processสี่เหลี่ยมมีเส้นแนวตั้งขนาบข้างเรียกใช้ฟังก์ชันหรือโปรแกรมย่อย (Subroutine)
Manual Input / Operationสี่เหลี่ยมขอบบนเอียง / คางหมูกลับหัวป้อนข้อมูลด้วยมือมนุษย์ / ปฏิบัติงานด้วยมือไม่ผ่านคอมพิวเตอร์
Document / Stored Data / DBขอบล่างคลื่น / โค้งบาน / ทรงกระบอกรายงานเอกสาร / สื่อบันทึกทั่วไป / ฐานข้อมูล Direct Access

DEBUGGING • 4 LOGIC ERROR TAXONOMY (NOTEBOOKLM)

อนุกรมความผิดพลาดเชิงตรรกะ 4 รูปแบบที่พบบ่อยใน Trace Table

Fail-Safe & Dry Run Rules
1. Off-by-One Error
ใช้ <= แทน < ทำให้ลูปเกิน/ขาด 1 รอบ จ่ายสารเคมีเกินขนาด
2. Uninitialized / Reset
ลืมกำหนดค่าในบล็อก Preparation (หกเหลี่ยม) หรือวาง total ← 0 ในลูป
3. Infinite Loop
ลืมอัปเดตตัวแปรควบคุมลูป (TotalCycles ← TotalCycles + 1) ทำให้ปั๊มทำงานค้าง
4. Actuator Chatter
สลับ ON/OFF ถี่ที่ค่าขอบเขต แก้ด้วยช่วง Deadband (35–40°C) + Fail-Safe Reset OFF
